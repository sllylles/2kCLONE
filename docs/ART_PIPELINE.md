# Art pipeline

All player art comes from CC0 sources and is built by one script:
`tools/blender/build_player.py` → `assets/players/player.glb` + `player_meta.json`.
The glb is committed, so building the game never needs Blender. Re-run the script
only when you change the body, garments or blend shapes.

## Sources (all CC0)

| What | From |
|---|---|
| Base body mesh, macro/face targets, `game_engine` skeleton + skin weights | MPFB2 bundled data (`src/mpfb/data`, CC0 asset license) |
| Hair (10 styles) | `hair/` in this repo (MakeHuman, CC0) |
| Eyes + iris texture | `eyes/` in this repo (MakeHuman, CC0) |
| Jersey, shorts, shoes | generated by the script from the body surface |

MPFB2's *code* is GPL; it is used only as a build tool and is not shipped in the game.

## Running it

Either real Blender (4.2+) or the `bpy` module from PyPI works.

```bash
# 1. Blender as a Python module (Python 3.13 for bpy 5.2)
python3 -m venv ~/bpyenv && ~/bpyenv/bin/pip install bpy==5.2.3

# 2. MPFB2 as a Blender user extension
git clone --depth 1 https://github.com/makehumancommunity/mpfb2 /tmp/mpfb2
mkdir -p ~/.config/blender/5.2/extensions/user_default
cp -r /tmp/mpfb2/src/mpfb ~/.config/blender/5.2/extensions/user_default/mpfb

# 3. Build (≈15 s)
~/bpyenv/bin/python tools/blender/build_player.py
#   or: blender --background --python tools/blender/build_player.py

# 4. Re-import in Godot (or just open the editor)
godot --headless --path . --import
```

## What the script does

1. **Base athlete** — MPFB2 `create_human` with macros: male, 25, muscle 0.68,
   weight 0.42, ideal proportions, height 0.7 → **2.015 m (6'7")**, the league average.
2. **Blend shapes** — captured as deltas against the base, so they stack at runtime:
   - build: `build_heavy`, `build_light`, `build_muscular`, `build_slim`
   - face sliders: `head_round/square/oval/long/wide`, `jaw_wide`, `chin_strong`,
     `nose_wide/narrow/long`, `lips_full`, `cheeks_high`, `brow_heavy`, `eyes_narrow`,
     `ears_big`, `neck_thick`
   - ancestry face blends `face_african/asian/caucasian` (customization only, never auto-assigned)
3. **Skeleton** — `game_engine` rig (53 bones, UE-style names: `pelvis`, `spine_01..03`,
   `upperarm_l`, `thigh_r`, …) with MakeHuman's skin weights.
4. **Eyes and hair** — fitted with MPFB2's `.mhclo` fitting, skinned to the head.
   Hair textures are downscaled to 512 px.
5. **Helpers removed** — MakeHuman's joint cubes and proxy helpers are deleted.
6. **Uniform** — the jersey (tank top cut from body measurements: straps, scooped
   neckline, armholes), shorts (flared toward the hem) and high-top shoes are copies of
   body faces pushed outward. They keep the body's skin weights **and every blend
   shape**, so they change build with the player. Hems are smoothed; shoes are fully
   smoothed with a thicker sole. Jersey/shorts get a cylindrical "Wrap" UV (front
   center u = 0.5) that `shaders/uniform.gdshader` uses for team colors, trim, the team
   name and front/back numbers.
7. **Hidden skin removed** — body faces under the uniform are deleted (keeping a
   one-face border) so skin never pokes through and the body drops to ~18.8k triangles.
8. **Export** — glTF binary, Y-up, meters, skins + morph targets. Godot generates mesh LODs on import.

Triangle budget per player: body 18.8k + jersey 2.4k + shorts 1.8k + shoes 4.4k +
hair 1–8k ≈ 28–35k at LOD0; distant players use the automatic LODs.

## In the game

`scripts/player/player_avatar.gd` dresses the shared model per player:
- **height** → uniform scale from the 2.015 m base
- **wingspan** → lengthens the forearm/hand bone offsets (not the thickness)
- **weight + height (BMI)** → `build_heavy` / `build_light`; **strength** → `build_muscular` / `build_slim`
- **face** → roster `"face": {"jaw_wide": 0.5, ...}`, else a stable per-player variation
- **skin / hair / hair_color** → roster fields (`"skin": "#8D5524"`, `"hair": "afro01"`); defaults are neutral
- **uniform** → home white / away team color, numbers and team name drawn by the shader

## Animations

Hand-authored poses in `data/animations/*.json`, turned into Godot Animations by
`scripts/player/anim_library.gd`. Poses use joint terms (bend, fwd, side, twist,
curl) in the character's frame, so they're readable and editable; left/right
mirroring is automatic. See the header of `anim_library.gd` for the conventions and
`tools/anim_sheet.sh` to render contact sheets while editing. No third-party
animation files are used.
